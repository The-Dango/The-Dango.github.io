# the-dango.github.io

Only here to keep old Loopism links working. The game lives at https://loopism.ca.

`Loopism/` (and `loopism/`) is the page left at the game's old address,
the-dango.github.io/Loopism/: it carries a device's saved game across to loopism.ca in the
link, switches off the old address's service worker and its kept copies, and forwards.
Its source is `tools/redirect/` in the (private) Loopism repo; change it there and copy
it here. Nothing else belongs in this repo.
